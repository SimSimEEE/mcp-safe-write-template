# Demo: read → preview → confirm → execute → audit

Generated by `npm run demo -- --out docs/demo.md` — a real MCP client (`@modelcontextprotocol/sdk`)
talking to the built server (`node dist/index.js`) over stdio. Nothing here is hand-written.
Keys are the public demo keys from `config/keys.example.json`. Each connection spawns its own
server process, and the example store is in memory, so every connection starts from the same seed data.

## 1. Server start (stderr)

```text
[mcp-safe-write] ready as key "demo-operator" scopes=[orders:read,orders:write:status,orders:write:cancel,orders:write:note] audit=<tmp>/audit.jsonl
```

| `get_order` | true | false |
| `preview_update_order_status` | true | false |
| `preview_cancel_order` | true | false |
| `preview_add_order_note` | true | false |
| `execute_plan` | false | true |
